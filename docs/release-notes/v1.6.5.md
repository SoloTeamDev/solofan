# Release Notes — v1.6.5 (2026-07-16)

## Highlights

- **Menu bar popover** — Left-click opens the SoloFan dashboard again (lazy content attaches on open as designed).

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/mohamadlounnas/ffan/main/scripts/install.sh | bash
```

Or download `solofan-v1.6.5-macos.dmg` from [GitHub Releases](https://github.com/mohamadlounnas/ffan/releases/latest).

## Requirements

- macOS **26.1** or later
- Apple Silicon or Intel
