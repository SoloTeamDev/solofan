# Release Notes — v1.6.6 (2026-07-16)

## Highlights

- **Developer ID signed + notarized** — GitHub Actions ships Gatekeeper-ready builds: the app, nested `smc-helper` / `smc-write`, and DMG are signed, notarized, and stapled.
- **Menu bar popover** — Left-click opens the SoloFan dashboard again (fix from v1.6.5; lazy content attaches on open as designed).

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/mohamadlounnas/ffan/main/scripts/install.sh | bash
```

Or download `solofan-v1.6.6-macos.dmg` from [GitHub Releases](https://github.com/mohamadlounnas/ffan/releases/latest).

## Requirements

- macOS **26.1** or later
- Apple Silicon or Intel
