# Release Notes — v1.6.4 (2026-07-16)

## Highlights

- **M4/M5 fan control** — Manual speeds work again when thermalmonitord holds fans in system mode.
- **Real Apple Silicon temps** — CPU/GPU track die-cluster sensors instead of gated cores (~2°C ghosts).
- **Stability & performance** — Persistent auto max-speed, quieter menu-bar icon, lazy popover, safer SMC helper.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/mohamadlounnas/ffan/main/scripts/install.sh | bash
```

Or download `solofan-v1.6.4-macos.dmg` from [GitHub Releases](https://github.com/mohamadlounnas/ffan/releases/latest).

## Requirements

- macOS **26.1** or later
- Apple Silicon or Intel
